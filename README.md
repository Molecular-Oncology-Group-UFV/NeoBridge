# NeoBridge: A Generalizable Neoantigen Prioritization Framework

> **Manuscript:** *NeoBridge enables generalizable neoantigen prioritization by integrating biophysical determinants of T cell recognition*
> Submitted to *Cell Genomics*

This repository contains the official source code, pre-trained models, and reproducibility scripts for the manuscript: *"NeoBridge enables generalizable neoantigen prioritization by integrating biophysical determinants of T cell recognition"* (submitted to *Cell Genomics*).

NeoBridge is a hybrid machine learning ensemble integrating gradient boosting (XGBoost) and a deep neural network (MLP) to prioritize clinically actionable neoantigens, particularly in low-mutation-burden tumors such as Pancreatic Ductal Adenocarcinoma (PDAC).

## 1. Repository Structure

The repository follows standard computational biology practices to separate source code, data, serialized models, and analytical outputs:

- `data/`: Directory for raw, interim, and processed datasets. *(Note: Raw data must be downloaded separately; see Data Access section).*
- `models/`: Pre-trained model weights, configuration files, and fitted scalers (`.pkl`, `.json`, `.pth`).
  Provided for direct inference without retraining. If omitted, all artifacts are automatically regenerated by executing Step 4.1.
- `notebooks/`: Jupyter notebooks for post-hoc statistical analysis, multi-omic evaluation, and generation of complex figures.
- `results/`: Automated output directory containing all generated figures (`results/figures/`), logs, and tabular reports (`results/reports/`) discussed in the manuscript.
- `src/`: Core Python source code organized into modular packages (`models`, `evaluation`, `visualization`, and `caracterization`).

## 2. Environment Setup

To ensure computational reproducibility, a Conda environment file is provided. The framework is built on Python 3.10 and relies on standard scientific libraries (PyTorch, XGBoost, Scikit-learn, Pandas, etc.).

To instantiate the environment, run the provided shell script or execute the conda command directly:

```bash
# Option A: Use the provided configuration script
bash Create_Conda_imblearn.sh

# Option B: Standard Conda installation
conda env create -f environment.yml
conda activate imblearn
```

## 3. Data Access and Preparation

Due to file size constraints and data sharing policies regarding patient-derived genomic sequences (ICGC ARGO), the `data/raw/` directory is not populated in the public GitHub repository.

To run the codebase, reviewers and researchers must obtain the raw dataset archive:

1. Download the raw data archive from Figshare: *[https://figshare.com/s/f26090848e24521dea6b]*
2. Extract the `.zip` file directly into the root directory of this repository. This action will automatically populate the `data/raw/` folder with `NeoPepBase.csv`, the PDAC clinical data, GTEx matrices, and required Position Weight Matrices (PWMs).

## 4. Reproducibility and Usage Pipeline

The analytical pipeline is designed to be executed sequentially. All scripts should be run from the root directory of the repository.

### Step 4.1: Model Training and Optimization

To train the NeoBridge Hybrid Ensemble from scratch using the curated pan-cancer dataset:

```bash
python src/models/MLP_XGBoost_Predictor.py
```

This script handles data preprocessing, hyperparameter optimization, and saves the final serialized model artifacts into `models/production/hybrid_ensemble/`.

### Step 4.2: Clinical Cohort Prediction (PDAC Inference)

To apply the trained NeoBridge model to the independent PDAC cohort (ICGC ARGO) and generate immunogenicity probabilities:

```bash
python src/Predict_And_Evaluate.py
```

This step reads the raw variant files, generates feature embeddings, and outputs the final classifications to `data/processed/Full_Dataset_Predictions.csv`.

### Step 4.3: Generation of Manuscript Figures and Benchmarks

Automated scripts are provided to recreate all performance metrics, benchmarking comparisons, and ROC curves featured in the manuscript. Execute the files within the visualization module:

```bash
python src/visualization/Benchmarking_Models.py
python src/visualization/Cancer_Combined_Roc_Curves.py
python src/visualization/Cohort_Scaling_Curve_Benchmark.py
python src/visualization/Neoantigens_Per_Cancer_Cohort.py
```

All generated plots will be saved in high resolution to `results/figures/`.

### Step 4.4: Advanced Post-Hoc Analysis

Further analytical validation, sequence homology auditing, and survival analyses are conducted via Jupyter Notebooks. Execute the following notebooks in order to generate the respective figures:

1. `notebooks/01_GenerateSankey_FromLatexTable.ipynb`
2. `notebooks/03_Evaluate_Proteomics.ipynb`
3. `notebooks/04_Post_Hoc_PepHLA_similitude.ipynb`
4. `notebooks/05_Prefilter_Checks.ipynb`
5. `notebooks/06_Survival_With_Phylogeny.ipynb`

> **Note:** `notebooks/02_Proteomal_Finding.ipynb` is an internal utility script used exclusively to generate targeted FASTA inputs for FragPipe mass spectrometry searches and is not required for standard pipeline reproduction.
